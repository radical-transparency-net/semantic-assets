# Claude Code Project Guidelines

Please consult and strictly adhere to the repository directives defined in [AGENTS.md](AGENTS.md).

Key Highlights:
- Keep all committed files in factual English.
- Treat Turtle (`weblink/weblink.ttl`) as the canonical vocabulary source and keep `weblink.jsonld`, `weblink.linkset*`, `weblink/index.html`, and the `w3id.org` `ids/rt/` redirects in sync.
- Validate JSON-LD, Turtle, and HTML rendering before finishing.
