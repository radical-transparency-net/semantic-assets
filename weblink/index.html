Radical Transparency Web Linking Vocabulary (rtwl:)

Turtle (weblink.ttl) JSON-LD (weblink.jsonld) Linkset JSON (RT-P03) Linkset Text (RT-P03) Example (observed-links.ttl) RT Linkset Usage Patterns

Overview

Neither RFC 8288 (Web Linking) nor RFC 9264 (Linksets) defines a normative RDF reification vocabulary for web links and their target attributes. rtwl: provides a minimal, lossless data model to record observed links factually without inventing non-existent terms under existing W3C namespaces.

Following RT-P03 (Content Negotiation Menu), the persistent namespace URI https://w3id.org/rt/ns/weblink exposes an explicit JSON linkset and text linkset listing all available formats and preserving rel="self" identity backlinks across redirects.

Open Design Review Points (v0.1.0-draft):
  1. RDFS vs. OWL 2 DL for rtwl:rel & rtwl:value: Currently typed as flexible rdf:Property so both string literals ("alternate", "text/turtle") and IRIs (<http://schema.org/hasPart>, profile URIs) are valid. Decide whether strict OWL 2 DL separation is needed.
  2. rtwl:Linkset & rtwl:link: Included as optional draft terms for attaching observation provenance (e.g., dcterms:source) to a harvested set of links.

Classes

rtwl:WebLink owl:Class

A reified representation of an observed typed web link as defined by RFC 8288 (anchor, link relation, target URI, and optional target attributes).

rtwl:TargetAttribute owl:Class

A key-value attribute qualifying a reified rtwl:WebLink target, corresponding to an RFC 8288 Section 3.4 link-param (e.g., type, profile, hreflang, title).

rtwl:Linkset owl:Class · draft candidate

A collection of reified rtwl:WebLink assertions observed together from a single HTTP response, Linkset document (RFC 9264), HTML document, or XML Sitemap.

Properties

rtwl:anchor owl:ObjectProperty

Domain: rtwl:WebLink · Range: rdfs:Resource. The link context / anchor resource (RFC 8288 §3.2) from which the link originates.

rtwl:href owl:ObjectProperty

Domain: rtwl:WebLink · Range: rdfs:Resource. The target resource IRI (RFC 8288 §3.1) to which the link points.

rtwl:rel rdf:Property

Domain: rtwl:WebLink. Either an IANA-registered relation token literal (e.g., "alternate") or an extension relation IRI (e.g., <http://schema.org/hasPart>).

rtwl:attribute owl:ObjectProperty

Domain: rtwl:WebLink · Range: rtwl:TargetAttribute. Links a reified web link to its target attribute nodes.

rtwl:key owl:DatatypeProperty

Domain: rtwl:TargetAttribute · Range: xsd:string. Parameter name of the target attribute (e.g., "type", "profile").

rtwl:value rdf:Property

Domain: rtwl:TargetAttribute. Value of the target attribute: either a literal (e.g., "text/turtle") or an IRI (e.g., a profile URI).

rtwl:link owl:ObjectProperty · draft candidate

Domain: rtwl:Linkset · Range: rtwl:WebLink. Associates a rtwl:Linkset observation container with a member rtwl:WebLink.

Example (Turtle)

@prefix rtwl: <https://w3id.org/rt/ns/weblink#> .

[] a rtwl:WebLink ;
   rtwl:anchor <https://example.org/resource> ;
   rtwl:rel "alternate" ;
   rtwl:href <https://example.org/resource.ttl> ;
   rtwl:attribute [
       a rtwl:TargetAttribute ;
       rtwl:key "type" ;
       rtwl:value "text/turtle"
   ] , [
       a rtwl:TargetAttribute ;
       rtwl:key "profile" ;
       rtwl:value <https://example.org/profiles/marine-ctd-v2>
   ] .
